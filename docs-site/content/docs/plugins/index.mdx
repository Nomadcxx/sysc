title: Plugins
description: Find the plugin catalog and propose official inclusion through sysc-plugins.
---


Authors can propose a plugin for the official source with a pull request to [sysc-plugins](https://github.com/Nomadcxx/sysc-plugins). Maintainers decide whether to accept each proposal. The project does not promise a review time.

Browse the [published catalog snapshot](./catalog) or [author an independent source](./publish). The catalog schema keeps license metadata optional. A checksum confirms that downloaded content matches its catalog entry; it does not endorse the plugin. Host capabilities limit plugin API calls, but they do not sandbox a same-user executable.

The authoring pages cover the SDK, manifest, protocol, accessible views, tests, release process, and catalog submission.
