The suite installs the versions listed in its manifest. Component pages follow the current default-branch source and state the exact SYSC v0.1.1 pin or status beside it.

Use the [source record](/docs/reference/sources) for full commit IDs and the [service integration guide](/docs/guides/service-integration) to see which process owns tray, clipboard and notification state.
