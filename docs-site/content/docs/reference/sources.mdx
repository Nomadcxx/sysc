## Plugin SDK version

At the recorded [`sysc-plugins` revision](https://github.com/Nomadcxx/sysc-plugins/blob/b6323d6f131bc8fa2d814942b271faecd045522a/go.mod), Go selects sysc-shell `v0.0.0-20261005234519-d16632ff376f`, which resolves to [commit `d16632ff376fc86cd585d6e90eb6c87b59a8637d`](https://github.com/Nomadcxx/sysc-shell/commit/d16632ff376fc86cd585d6e90eb6c87b59a8637d). That module supplies `plugin/v1` and `plugin/lint`. Their public types and constants match the current sysc-shell source above, but the shell's internal layout code changed after this dependency. Plugin tests against the pinned linter therefore do not establish identical rendering in a newer shell.

The v0.1.1 manifest lists the suite pins. The installer workflow publishes installer binaries; each component publishes its own assets. Check the component release before inferring availability from the installer's architecture matrix. Component articles will link the relevant source files and call out behavior differences from the suite pin.
