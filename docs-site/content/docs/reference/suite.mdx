## SYSC v0.1.5 suite pins

The installer embeds this component set in its v0.1.5 binary. It downloads the listed amd64 release assets over HTTPS and verifies their SHA-256 values from the [pin manifest](https://github.com/Nomadcxx/sysc/blob/v0.1.5/internal/pin/pin.json).

The v0.1.5 pin installs sysc-terminal v0.3.1 as a managed wallpaper executable, seeds tray presentation in a new config when sysc-tray installs, and leaves plugin installation to the shell's catalog.

## Enabled user services

- **sysc-shell v0.2.0:** sysc-shell.service
- **sysc-clipboard v0.1.4:** sysc-clipboard.service
- **sysc-walls v1.4.1:** sysc-walls.service
- **sysc-notify v0.1.2:** sysc-notify.service
- **sysc-tray v0.1.3:** sysc-tray.service
- **sysc-lock v0.1.4:** sysc-lock-session.service

## Disabled and optional

- **sysc-terminal v0.3.1:** a binary-only component; the shell manages its wallpaper processes and it has no user unit.
- **gSlapper v1.5.3:** an optional package; SYSC installs it only when it is missing.

All enabled component binary assets in this pin are amd64. SYSC also publishes an arm64 installer executable, but the installer refuses to install this suite on arm64.

gSlapper has an Arch package route through yay or paru, plus pinned amd64 packages for Debian 13, Ubuntu 24.04, Ubuntu 25.x and Fedora 42+. These routes cover gSlapper only. SYSC preflight still gates the complete suite to the Arch family.

sysc-greet is a separate greeter project. sysc-wayland, sysc-metrics and sysc-launch are libraries or tools that the installer does not install. The [source record](/docs/reference/sources) shows current default-branch commits for these projects separately from the suite release pins.
