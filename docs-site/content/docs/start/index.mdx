---
title: Install SYSC
description: Check the SYSC v0.1.1 support route and component pins before you install.
---


Check the requirements first, then install the pinned SYSC v0.1.1 release. Run the installer as your normal user on an Arch-family x86_64 system with Niri and systemd user services ready.

The wizard records theme, wallpaper, plugin, weather and conflict choices. After it finishes, check the user services from the active Niri session.
