---
title: Install SYSC
description: Check the SYSC v0.1.1 support route and component pins before you install.
---


Check the requirements first, then choose the guided SYSC v0.1.1 installer or the AUR package route. On the AUR, start with sysc-shell; your helper installs its companions. Both routes target Arch-family x86_64 with Niri and systemd user services. Full Debian and Fedora support is planned.

The wizard records theme, wallpaper, plugin, weather and conflict choices. After it finishes, check the user services from the active Niri session.
